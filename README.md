# Reimplementing Natural Language Autoencoders on Qwen2.5-0.5B: An Empirical Scaling and Failure-Mode Study

This repository contains my independent replication and diagnostic analysis of Anthropic's 2026 methodology: *Natural Language Autoencoders Produce Unsupervised Explanations of LLM Activations*. 

Due to local compute constraints (testing on a single CPU/free-tier resource), I scaled the methodology down from billions of parameters to an expressive, compact open-source base model: `Qwen/Qwen2.5-0.5B`. Rather than just seeking perfect metrics, my goal was to study how severe parameter bottlenecks and architectural differences distort the latent geometry when passed through a natural language bottleneck.

---

## 1. Simplified Architecture & Engineering Choices

Anthropic’s production pipeline uses massive joint orchestration systems (Miles) and highly optimized inference runners (SGLang). To reproduce this logic on a lean setup, I built a self-contained pipeline using standard PyTorch hooks and Hugging Face token-splicing.

### The Pipeline Mechanics
1. **Activation Interception (`ActivationHook`):** I registered a forward hook on the residual stream of `Qwen2.5-0.5B` at **Layer 16** (roughly two-thirds into its 24-layer stack). I chose this layer because mid-to-late layers generally contain rich semantic abstractions before the geometry begins collapsing into raw vocabulary tokens.
2. **The Verbalizer Bottleneck (`ActivationVerbalizer`):** The hook extracts the hidden state $h_l \in \mathbb{R}^{896}$ from the final token position of a context prompt from WikiText. This vector is $L_2$-normalized and spliced directly into the target model's input embeddings as a pseudo-token right after the prefix sequence: *"The internal state of the model represents the concept of:"*.
3. **The Reconstructor Head (`ActivationReconstructor`):** The text explanation generated by the verbalizer is read by a second model instance. A custom linear projection layer (`nn.Linear(896, 896)`) evaluates the final hidden state of this text sequence and maps it back into a reconstruction vector $\hat{h}_l$.

### Hardware & Data Scope Alignment
To avoid runtime memory blowouts, I limited the evaluation dataset to 66 dense activations extracted from length-filtered validation splits of `wikitext-2-raw-v1`. Optimization was conducted over 5 epochs using AdamW ($\eta = 10^{-3}$) targeted purely at aligning the reconstruction projection head.

---

## 2. The Mathematical Formulation

To ensure scale variations between models didn't skew the results, all target and reconstructed vectors were unit-normalized ($L_2$) before tracking direction alignment via Cosine Similarity:

$$\mathcal{L}_{MSE} = \left\| \bar{h}_l - \overline{AR}(z) \right\|_2^2 = 2 \cdot (1 - \cos(\theta_{\text{vectors}}))$$

System tracking uses the **Fraction of Variance Explained (FVE)** as the primary performance metric to evaluate how much variance the autoencoder successfully captures compared to the global dataset mean:

$$FVE = 1 - \frac{\sum \| \bar{h}_l - \overline{AR}(z) \|_2^2}{\sum \| \bar{h}_l - \mathbb{E}[\bar{h}_l] \|_2^2}$$

## 3. Quantitative Results & Structural Trade-offs

The autoencoder successfully converged during the optimization phase, dropping the training MSE down cleanly from `0.00136` to `0.00048`. However, testing revealed a clear performance gap when compared to Anthropic's scale configurations.

| Configuration | Mean Cosine Similarity | Average MSE | Fraction of Variance Explained (FVE) |
| :--- | :--- | :--- | :--- |
| **Anthropic Baseline (Claude 3)** | 0.8100 – 0.8900 | 0.2200 | **0.6000 to 0.8000** |
| **My Implementation (Qwen2.5-0.5B)** | 0.4371 | 0.001255 | **-0.6377** |

### Why My Run Hit a Negative FVE
A negative FVE score means the reconstruction error vector is wider than the variance of the underlying sample data. Rather than a code bug, this is an informative structural failure mode directly tied to our downscaled setup:
* **The High Polysemanticity of Tiny Models:** Large models like Claude isolate concepts into distinct geometric directions. A 0.5B model relies heavily on *superposition*—packing multiple unrelated ideas into the same hidden dimensions. Forcing a polysemantic vector through a short text string throws away the nuanced directional components.
* **Narrow Baseline Variance:** Limiting our dataset to 66 test vectors concentrated the variance into a very tight cluster. Any slight translation errors caused by the linear reconstruction head overshot the edges of this distribution, driving the FVE into negative territory.

## 4. Qualitative Breakthroughs & Text Behavior Breakdown

Examining the actual strings generated by the verbalizer reveals exactly how base language models handle direct activation injection.

### Case 1: The Multiple-Choice Template Loop (Samples 1 & 3)
* **Generated Explanation 1:** `"A. the model's internal state\nB. the model's external state"` (Cosine Similarity: `0.4760`)
* **Generated Explanation 3:** `") A. the model's internal state B. the model's external state C"` (Cosine Similarity: `0.9342`)

**My Analysis:** Because `Qwen2.5-0.5B` is an autocompletion model rather than a chat-tuned assistant, it didn't inherently understand it was supposed to write an explanation. It treated the prefix string like an uncompleted multiple-choice question from an academic exam paper. 

The interesting part here is Sample 3's high Cosine Similarity (`0.9342`). Even though the generated text looks broken to a human reader, the structural text pattern was incredibly stable. This stability made it very easy for the linear projection layer to learn the pattern and map the final token state back onto the target coordinates.

### Case 2: Cross-Lingual Token Drift (Sample 2)
* **Generated Explanation 2:** `"子\nA. 事物\nB. 事物的运动状态\nC"` (Cosine Similarity: `0.0499`)

**My Analysis:** This case highlights a major failure mode in miniature interpretability models. Injecting an unaligned, raw activation vector directly into the input embeddings can inadvertently activate entirely different sub-networks inside the model. Here, the numerical properties of the vector overrode the English context prompt and pushed the attention heads straight into Qwen's Chinese pre-training data pathways. Because the language shifted mid-stream, the reconstruction alignment loop broke down completely, resulting in a near-zero similarity score (`0.0499`).
